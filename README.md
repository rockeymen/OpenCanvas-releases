# OpenCanvas

Official desktop download repository for OpenCanvas, an AI image workspace for macOS and Windows.

Website: https://canvas.pic-toolkit.one/

Download installers from this repository's Releases page. This repository distributes binaries only, not the application source code.

## Preview release notes

- macOS: Apple Silicon (arm64).
- Windows: x64. Windows builds have not yet been installation-tested on a physical Windows machine.
- Preview installers are not code-signed/notarized. Verify the publisher and download origin; do not disable system security protections.
- Bring your own API key. Model usage is charged by your selected provider.
- Projects are stored locally. AI requests send the relevant prompt and images to your selected provider.
- Updates check the public Cloudflare version manifest every 30 minutes. Downloads are hosted here and verified with SHA-256 before opening.

Brand icon candidates are still under review; preview packages retain a temporary icon.
